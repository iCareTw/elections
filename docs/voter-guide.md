# 選舉公報解析 (voter guide)

從中選會選舉公報 PDF 擷取候選人資料（號次、姓名、生日、性別、政黨、學歷、經歷、政見、相片）。
目前涵蓋三種擺法：

| 選舉 | 一組是誰 |
|---|---|
| 總統 | 正副兩人成一組 |
| 縣市長、區域立委、原住民立委、立委補選 | 一人一號 |
| 不分區立委 | 一個政黨一組，底下是名單第 1..N 名（人數不固定，政見屬於政黨） |

## 用法

```bash
# 解析 PDF → 每場一份 YAML（含每欄信心標記）與相片
uv run python -m src.voter_guide.pipeline <pdf...> --out-dir <dir>

# 匯入 DB 後於網頁檢視/校對(公報校對台):make web → /guide
```

**公報放在哪裡就代表它是哪一場選舉**，不必另外指定類型：

```
_data/voter_guide/president/113年第16任總統副總統.pdf   → 總統 2024 第16任
_data/voter_guide/mayor/111/臺北市市長.pdf              → 縣市長 2022 臺北市
_data/voter_guide/legislator/11th_113/02區域立法委員/02臺北市/第1選舉區/….pdf
                                                        → 立委 2024 第11屆 臺北市第1選舉區
```

立委四屆的目錄擺法不一致（`district`／`02區域立法委員` 都有），分類（區域／不分區／
原住民／補選）由分類目錄名判定，檔名寫著「補選、缺額」的以檔名為準。罷免案與投開票所
地點不是公報，匯入清單不列。校對台左樹的層級也由這裡產生（`nav_path`）。

## 運作方式

- **切分**：以表格框線把每位參選人、每個欄位切成單格取文字（`geometry`）。
- **驗證**：把單格截圖交給本機視覺模型「盲讀」當獨立第二來源（`vision`），
  程式比對兩路一致度，標成五級信心：完全一致／幾乎一致／大部分一致／資料不可靠／無法解析（`verify`）。
- **切分來源依 PDF 裡實際有什麼自動退讓**（純程式判斷，不打模型）：

  | PDF 裡有什麼 | 總統怎麼切 | 縣市長怎麼切 |
  |---|---|---|
  | 內嵌文字 | `geometry` | `table_parse` |
  | 只有向量格線 | `apple_ocr` 逐格看圖 | — |
  | 文字被畫成曲線／只有掃描照片 | `scan_parse` 自己找格線 | `scan_table` 自己找格線 |

- **不預設版面長相**：欄位名（姓名、出生年月日…）共線的方向就是表頭軸，垂直於它
  的方向就是候選人並排的方向；表頭軸靠頁面右緣即為早期的直書右到左版式。八份
  president 公報涵蓋六種版面，全部由此推導，沒有為年份寫特例。

### 縣市長公報的兩個額外難處

各縣市選委會各自排版，22 份長相都不同，`table_parse` 用兩條規則吸收：

1. **一份 PDF 常同時刊多場選舉**（市長 + 議員各選舉區）。以段落標題（「市長候選人」、
   「第12選舉區（平地原住民）候選人」）判定每位候選人屬於哪一場；比對的是候選人所在
   的 y 位置落在哪個標題之後，所以連「同一張表格上半市長、下半議員」也切得開。

2. **四種版式**，由表格自身判定，不看縣市名：

   | 版式 | 長相 | 例 |
   |---|---|---|
   | H 表頭列 | 一列全是欄名，其後每列一位候選人 | 桃園、臺中、彰化 |
   | I 內嵌欄名 | 每位候選人一張卡片，欄名與值成對相鄰 | 新北、臺南 |
   | V 直式欄名 | 一張表格一位候選人，欄名在上、值在正下方 | 臺北 |
   | 重複表頭 | 整組欄名重複 → 同一列並排多位候選人 | 新竹市 |

   另外直書欄名常被表格線切成上下兩段（金門的「號／次」），併回去才讀得到值。

3. **段落標題的取捨隨本場而異**：縣市長公報要濾掉議員，立委公報反而必須留下寫著
   「第1選舉區」的段落，所以兩者各有一組 keep／skip 規則。

### 不分區公報

一個政黨一組、成員人數不固定，`party_list_parse` 用一台跨頁的狀態機讀：把每一頁的
直欄由左到右、由上到下攤成一條閱讀順序，遇到「號次·名稱」換一個政黨、遇到「名單次序」
換一組欄位對照，其餘有名單次序的列都算在當下那個政黨名下。兩種版面共用這套讀法：

- 101／105／109：一整頁是一張大表格，實際是報紙式的 2~3 直欄，名單常從左欄接到中欄、
  右欄、下一頁。
- 113：一個政黨一張小表格，排成兩直欄；`find_tables()` 給的順序不是閱讀順序，
  要先按「左緣分欄、同欄由上而下」排過，否則接續的名單會算到別的政黨頭上。

## 模組

`src/voter_guide/`：`election_meta`（PDF 位置 → 是哪一場選舉）、`geometry`（讀 PDF 文字）、`table_parse`（縣市長表格切分）、`apple_ocr`（Vision OCR 逐格）、`layout`（版面推導）、`scan_grid`（找格線）、`scan_parse`／`scan_table`（看圖切表）、`vision`（盲讀）、`verify`（信心）、`pipeline`（串接）、`guide_load`（匯入 DB）、`guide_repair`（AI 修復）、`guide_crop`（照片裁切）。網頁檢視/校對在 `src/webapp/routes/guide.py` 與 `templates/guide/`。

掃描圖那條路的三個關鍵（都是實測踩出來的）：掃描歪 0.2 度就會讓投影找不到線，需
先校正；085 是淺藍印刷，二值化門檻必須看背景亮度定；直排文字整欄都是墨，只能靠
「線很細、貫穿整個表格高度」與文字欄區分。
